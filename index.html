Firebase Configuration

ใส่ค่า Firebase Web Config ในตัวแปร firebaseConfig ภายในไฟล์ HTML นี้ แล้วเปิดใช้งาน Firebase Authentication และ Firestore เพื่อซิงก์ข้อมูลบนคลาวด์

ยังไม่ได้ตั้งค่า Firebase
ความปลอดภัย: อย่าใส่ Service Account Private Key, รหัสผ่าน หรือ secret key ในไฟล์ HTML ที่เผยแพร่สู่สาธารณะ ค่า Firebase Web Config เป็น client config แต่ต้องตั้ง Firestore Security Rules ให้ถูกต้อง
